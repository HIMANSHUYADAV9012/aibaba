📊 System Architecture:

Frontend → API Calls → Telegram Notification → AI Analysis → Display

🔄 Real-time Flow:

  1. User enters Instagram username
  2. Telegram notification #1 sent
  3. Fetch request to scraping API
  4. Get profile data (JSON format)
  5. Display basic stats immediately
  6. Send data to ChatGPT API
  7. Telegram notification #2 sent with report
  8. Format and display final report

🔧 Technologies Used:

  • • HTML5 + Tailwind CSS (UI)
  • • JavaScript (Interactivity)
  • • Instagram Scraping API
  • • ChatGPT/OpenAI API (Analysis)
  • • Telegram Bot API (Notifications)
  • • CSS Animations (Effects)

📡 API Endpoints:

GET https://mainapi-lake.vercel.app/scrape/{username}
POST https://baba-backend.vercel.app/generate-report
POST https://api.telegram.org/botTOKEN/sendMessage
